# Dream'z Kebab – Website

Statische Website (HTML/CSS/JS, ohne Build-Schritt) für Dream'z Kebab mit den Filialen
**Mexikoplatz** (Mexikoplatz 1) und **Krumme Lanke** (Fischerhüttenstraße 89), 14163 Berlin.

## Dateien
- `index.html` – Startseite: Hero, Speisekarte, Filialen, Kontakt
- `styles.css` – Design (Neon/Ziegel-Look)
- `script.js` – „Jetzt geöffnet"-Anzeige; Öffnungszeiten oben in `HOURS` pflegen
- `impressum.html`, `datenschutz.html` – Rechtliches (gelb markierte Platzhalter ausfüllen!)

## Ansehen
`index.html` im Browser öffnen oder `python3 -m http.server` und http://localhost:8000 aufrufen.

## Veröffentlichen (GitHub Pages)
Repository → Settings → Pages → Branch wählen → Ordner `/ (root)` → Save.

## Pflege
Öffnungszeiten stehen an zwei Stellen: in der Tabelle in `index.html` und in `HOURS` in `script.js`.
